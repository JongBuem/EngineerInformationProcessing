C언어 — 구조체 내 함수 포인터

C · Struct · Function Pointer · Pointer Arithmetic · %x Hex Output
Q문제 코드
C Language 구조체 · 함수 포인터 · 포인터 산술 · 16진수
C 
struct fns {
    int* (*fn)(int*);  // fn: int*를 받아 int*를 반환하는 함수 포인터
} mine;

int* dummy(int *d) {
    return d + 1;      // 포인터 산술: int* 기준 +1 → 4바이트 이동
}

int main() {
    struct fns mine;
    int n[] = {16, 32};  // n[0]=16(0x10), n[1]=32(0x20)
    mine.fn = dummy;    // 구조체 함수 포인터에 dummy 주소 대입
    printf("%x", *mine.fn(n)); // ① 함수 호출 → ② 역참조 → ③ 16진수 출력
    return 0;
}

위 코드의 출력값은 무엇인가?

printf("%x") 출력 결과
20
n[1]=32 → 16진수 변환 → 0x20 → "%x" 출력: 20
① 문제 유형

구조체 멤버 함수 포인터를 통해 함수를 호출하고, 포인터 산술로 이동한 주소를 역참조한 값을 16진수로 출력하는 복합 포인터 문제입니다.

② 배열 메모리 레이아웃
n[0] ← n (시작주소)
16
0x10
n[1] ← n+1 (4바이트 이동)
32
0x20 ← 출력!

int 크기 = 4바이트 → n+1은 n[0]주소 + 4byte = n[1]의 주소

③ 연쇄 호출 단계별 분해
1 mine.fn = dummy → fn에 dummy 함수 주소 저장 구조체 함수 포인터 대입
2 mine.fn(n) → dummy(n) 호출 n = &n[0] 전달
3 dummy 내부: d+1 → &n[1] 반환 int* +1 → 4바이트 이동 → n[1] 주소
4 *mine.fn(n) → *(&n[1]) = n[1] = 32 반환된 포인터를 역참조
5 printf("%x", 32) → 출력: 20 32 = 2×16 + 0 → 16진수 20
④ 10진수 → 16진수 변환 확인
10진수÷16 몫나머지16진수
3220—
202→ 20 (위에서 아래: 2, 0)

32(10) = 2×16¹ + 0×16⁰ = 0x20 → %x 서식: 20

⑤ 함수 포인터 선언 독해
  • 🔷int* (*fn)(int*) 읽는 법: fn은 (int*를 받아 int*를 반환하는) 함수의 포인터
  • 🔷괄호 안쪽 *fn이 핵심 — 괄호 없으면 int* *fn(int*)가 되어 함수 선언이 됨
  • ✅mine.fn(n) = 구조체 멤버 fn 함수 포인터로 호출 → dummy(n) 실행
