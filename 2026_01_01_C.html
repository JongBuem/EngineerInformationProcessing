C언어 — 배열 평균 합산

C · Array · Function · Pointer Arithmetic · Double Output
Q문제 코드
C Language 배열 · 함수 포인터 · 실수 출력
C 
#include <stdio.h>

double arr1(int p[], int len) {   // ① p[]방식: 배열 첨자
    double av = 0;
    int i;
    for (i = 0; i < len; i++) {
        av += (double) p[i];        // int → double 캐스팅 후 합산
    }
    return av / len;               // 합 ÷ 개수 = 평균
}

double arr2(int *p, int len) {    // ② *p방식: 포인터 산술
    double av = 0;
    int i;
    for (i = 0; i < len; i++) {
        av += (double)(*(p + i));   // *(p+i) ≡ p[i] 완전히 동일
    }
    return av / len;
}

int main() {
    int arr[10] = {80,20,50,55,45,95,55,10,40,80};
    int len = 10;
    printf("%.2f", arr1(arr, len) + arr2(arr, len));  // 두 평균의 합
    return 0;
}

위 코드의 출력값은 무엇인가?

printf("%.2f") 출력 결과
106.00
arr1 평균 53.00 + arr2 평균 53.00 = 106.00
① 문제 유형

배열을 두 가지 방식(첨자 vs 포인터 산술)으로 접근해 평균을 구한 뒤 합산하는 값을 %.2f로 출력하는 문제입니다.


  • 🔷arr1: int p[] — 배열 첨자 방식 p[i]
  • 🔷arr2: int *p — 포인터 산술 방식 *(p+i)
  • ✅p[i] 와 *(p+i)는 완전히 동일 → 두 함수 결과가 같음
② 연쇄 호출 단계별 분해
1 arr = {80,20,50,55,45,95,55,10,40,80} → 합계 530 10개 원소 전부 더함
2 arr1(arr, 10) → 530.0 / 10 double 나눗셈
3 530.0 / 10 → 53.00 arr1 반환값
4 arr2(arr, 10) → 53.00 *(p+i) ≡ p[i] → 동일 결과
5 53.00 + 53.00 → 106.00 printf("%.2f") 출력

④ 핵심 포인트
  • ✅함수 매개변수 int p[] 와 int *p 는 완전히 동일 — 컴파일러가 둘 다 포인터로 처리
  • ✅(double)p[i] 캐스팅으로 정수 → 실수 변환 후 합산하므로 소수점 정밀도 유지
  • ✅%.2f : 소수점 이하 2자리 고정 출력 → 106.00
