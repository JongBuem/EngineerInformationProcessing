Q문제 코드
Python 리스트 얕은 복사 · 참조 공유 · 누적 연산
Python 
def f(a):
    m = [[x] for x in a]    # m = [[1],[2],[3],[4]] — 각 원소를 리스트로 감쌈
    b = m[:]                   # 얕은 복사: b와 m은 내부 리스트 객체 공유!
    for i in range(len(b) - 1):
        b[i+1] += b[i]         # b[i+1] = b[i+1] + b[i] → 리스트 확장 연결
    return sum(len(x) for x in m)  # m의 각 원소 길이 합산 (b 아닌 m!)

print(f([1, 2, 3, 4]))

위 코드의 출력값은 무엇인가?

print(f([1,2,3,4])) 출력 결과
10
m 원소 길이 합: 1+2+3+4 = 10
① 문제 유형

Python 리스트 얕은 복사(shallow copy)로 b와 m이 내부 리스트 객체를 공유하기 때문에, b 조작이 m에도 그대로 반영되는 참조 공유 트래킹 문제입니다.

② 핵심 — 얕은 복사 vs 깊은 복사
  • ⚠️b = m[:] → 얕은 복사: b와 m은 다른 리스트 컨테이너지만, 내부 원소(리스트 객체들)는 같은 객체를 공유
  • ⚠️b[i+1] += b[i] = b[i+1] = b[i+1] + b[i] → 리스트 연결 → 새 리스트 객체 생성 후 b[i+1]에 재할당
  • ✅재할당된 새 객체가 m[i+1]과 같은 참조 → m도 변경됨!
③ 연쇄 호출 단계별 분해
1 m = [[1],[2],[3],[4]] → 4개 리스트 객체 생성 각 원소가 별도 리스트
2 b = m[:] → 얕은 복사 — 객체 공유! b[0]과 m[0]은 동일 객체 [1]
3 i=0: b[1] += b[0] → [2]+[1] = [2,1] m[1]도 [2,1]로 변경됨
4 i=1: b[2] += b[1] → [3]+[2,1] = [3,2,1] m[2]도 [3,2,1]로 변경됨
5 i=2: b[3] += b[2] → [4]+[3,2,1] = [4,3,2,1] m[3]도 [4,3,2,1]로 변경됨
6 sum(len(x) for x in m) → 1+2+3+4 = 10 m이 변경된 상태 기준으로 계산
