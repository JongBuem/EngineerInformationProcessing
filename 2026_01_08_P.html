Q문제 코드
Python 문자열 슬라이싱 · 역순 · 문자 필터
Python 
i = input()              # 입력값: "HumanDev"
x = []

for word in i.split():  # 공백 기준 분리 → 공백 없음 → ["HumanDev"]
    x.append(word)       # x = ["HumanDev"]

y = ''.join(x)           # 리스트 → 문자열: y = "HumanDev"
z = ''.join(c for c in y[::-1] if c not in 'ong')
# y[::-1] = "veDnamuH"  →  'o','n','g' 소문자 제거

print(z)

입력값으로 HumanDev를 주었을 때 출력값은 무엇인가?

print(z) 출력 결과
veDamuH
"HumanDev" → 역순 "veDnamuH" → 'n' 제거 → "veDamuH"
① 문제 유형

문자열을 역순 슬라이싱한 뒤 특정 소문자(o, n, g)를 제너레이터 표현식으로 걸러내는 문자열 처리 문제입니다.

② 연쇄 호출 단계별 분해
1 i = "HumanDev" → i.split() 공백 기준 분리
2 i.split() → ["HumanDev"] 공백 없음 → 원소 1개짜리 리스트
3 ''.join(["HumanDev"]) → y = "HumanDev" 원소 연결 → 원본과 동일
4 y[::-1] → "veDnamuH" step=-1: 끝부터 역순 순회
5 c not in 'ong' 필터 → 'n' 제거 'o','n','g' 소문자만 제거 (대소문자 구분)
6 ''.join(필터 결과) → z = "veDamuH" 최종 출력
③ "veDnamuH" 문자별 필터 단계별 추적
순서문자 cc in 'ong'?통과?z 누적
1vNo✅ 통과"v"
2eNo✅ 통과"ve"
3DNo✅ 통과"veD"
4nYes❌ 제거"veD"
5aNo✅ 통과"veDa"
6mNo✅ 통과"veDam"
7uNo✅ 통과"veDamu"
8HNo ('h'≠'H')✅ 통과"veDamuH"
④ 핵심 포인트
  • ⚠️'ong' 은 문자열 — 소문자 'o','n','g'만 필터. 대문자 'O','N','G','H' 등은 통과
  • ✅[::-1] = step이 -1 → 마지막 문자부터 역방향 전체 순회
  • 📌입력에 공백이 없으면 split() 후 join()해도 원본과 동일
