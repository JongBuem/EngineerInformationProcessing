Java — 정수 덧셈과 문자열 연결 연산

Java · String Concatenation · Type Promotion · + operator Left-to-Right
Q문제 코드
Java 타입 변환 · 문자열 연결 · + 연산자 순서
Java 
public class Main {
    public static void main(String[] args) {
        int x1 = 9;
        int x2 = 2;
        String x3 = "3";
        System.out.println(x1 + x2 + "2" + x3);
        // + 연산자는 왼쪽에서 오른쪽으로 평가됨
    }
}

위 코드의 출력값은 무엇인가?

System.out.println() 출력 결과
1123
9+2=11(int) → 11+"2"="112"(String) → "112"+"3"="1123"
① 문제 유형

Java의 + 연산자는 왼쪽에서 오른쪽으로 평가되며, 피연산자 중 하나라도 String이 되는 순간 이후 모든 + 는 문자열 연결로 전환되는 규칙을 묻는 문제입니다.

② 연쇄 호출 단계별 분해
1 x1 + x2 + "2" + x3 → 좌결합 순서로 분해 ((x1+x2)+"2")+x3
2 x1 + x2 = 9 + 2 → 11 int + int → int 덧셈
3 11 + "2" → "112" int + String → 11을 "11"로 변환 후 연결
4 "112" + x3 → "112" + "3" String + String → 문자열 연결
5 "112" + "3" → println("1123") 최종 출력
③ + 연산자 타입별 동작 규칙 정리
피연산자 조합결과 타입동작이 문제에서
int + intint숫자 덧셈9 + 2 = 11
int + StringStringint → String 자동변환 후 연결11 + "2" = "112"
String + StringString문자열 연결"112" + "3" = "1123"
④ 함정 — 괄호 위치가 바뀌면?
  • ⚠️x1 + (x2 + "2") + x3 라면: x2+"2" = "22" → 9+"22" = "922" → "922"+"3" = "9223"
  • ⚠️"" + x1 + x2 + "2" + x3 라면: ""가 앞에 오면 처음부터 String → "9223"
  • ✅이 문제는 앞에 int+int가 먼저 오므로 11이 계산된 뒤 문자열 연결 시작 → 1123
